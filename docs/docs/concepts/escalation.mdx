Review finds something. You fix it. Review finds something else. Fix that. Four rounds later you are
still fixing, and some of what you're fixing was introduced by your own earlier fixes.

That's the failure this page exists to stop. The signal is not the round count — it's **the same kind of
bug showing up twice**. When that happens, the next patch is worse than useless, because you're patching
a subsystem you haven't understood and each patch can spawn the next defect.

## Triage vs diagnosis

<CardGroup cols={2}>
  <Card title="Triage">
    Surface one symptom at a time. Fast, shallow, never names the underlying cause. Correct for rounds
    1–2.
  </Card>
  <Card title="Diagnosis">
    Find the *disease* behind a cluster of symptoms. Slow, deep, names the root.
  </Card>
</CardGroup>

## The ladder

| Rung | Mode | What happens |
| --- | --- | --- |
| **1 — Patch** | triage | Fix the reported defect. Normal for rounds 1–2. |
| **2 — Diagnose + fix** | diagnosis | Stop patching. Find the nest, apply one consolidating fix. Autonomous by default. |
| **3 — Stop** | escalate | Surface to the human, pre-validated. Rare. |

### Climb to rung 2 the moment any trigger fires

- **Class-recurrence** — the same bug-class a *second* time. The primary trigger; act on the recurrence,
  not on a count.
- **The tell** — a finding whose fix needs a *new mechanism* rather than a tightened check. When a fix
  adds machinery instead of narrowing an existing guard, the design has a hole near it.
- **Round-count backstop** — round **4**, whatever the findings look like. By four, a pattern is real.
  Hitting it *is* the climb, not a suggestion.

## The nest

The single design gap that generates a whole **cluster** of findings. *Stop hitting moles, find the
nest.*

A cluster is two or more findings that are the same underlying issue recurring at a different call site,
branch, or checkpoint. A shared *file* is not a shared shape; a shared **shape** is the signature of a
nest.

:::tip
The load-bearing move is reading the **whole subsystem, not the diff**. The diff shows where a mole
surfaced; it never shows the nest. Skip this and you patch the symptom again, one call site further along.
:::

The test for having read enough is being able to write the nest as one sentence — something like *"every
consumer of this state assumes it is fresh, but nothing re-reads it after the window opens."* No sentence
means not enough reading yet.

## Three verdicts

| Verdict | Meaning | What follows |
| --- | --- | --- |
| **code-wrong** | The implementation has a gap; the spec is sound. | Consolidating fix, continue. Rung 2, autonomous. |
| **node-wrong** | The spec or premise is wrong; no code change closes it honestly. | Do not fix. Escalate. Rung 3. |
| **independent** | The cluster dissolved; findings are genuinely unrelated. | Resume patching, now with confidence there is no nest. |

## Fix-completeness

Before any fix is done, enumerate **every branch and caller** its reasoning touches, and cover each.
This binds every fix on every rung — including the consolidating one.

This is the step consolidating fixes fail at. A shared guard that covers five of six call sites has not
closed the class — it has hidden five sixths of it, and the sixth reaches merge looking unrelated.

:::warning
Half a consolidation reopens the class it was meant to close. The call sites are found by searching the
subsystem for the shared state or invariant, not by re-reading the list of findings — the findings only
ever name the sites that happened to surface.
:::

## Autonomy

The **run profile** on the map decides how freely the inner loop runs:

- **autonomous** (default) — diagnose the nest, apply the consolidating fix, and continue without a
  human. Most escalations resolve and die here.
- **supervised** — diagnose autonomously, but return with the validated diagnosis *before* applying the
  fix.

Rung 3 fires only when diagnosis returns node-wrong, the node's proof cannot be gathered, or the fix
would cost more than the node is worth. It arrives pre-validated — the named nest, a confidence level,
and whether fixing it unblocks the graph — so it is a stop a human can act on, not a bare "I'm stuck."
